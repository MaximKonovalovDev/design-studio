# packs/
Reusable design packs shared across orders and samples.

- `vol0/` - base pack set for current orders.
- `donors/` - donor-sourced pack inputs (open-design).
- `plan-assemble-o040/` - working plan for order O040 assembly.

Open first: `vol0/` overview, then the pack you need.
Keep packs source-only; rendered output lives in `designs/`.
See `samples/` for usage examples of these packs.
