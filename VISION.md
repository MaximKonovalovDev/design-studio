# VISION: design-studio (2026-10-03)

design-studio is Maxim's autonomous, growing AI design studio. It makes all the design the other repos and products need: covers, ads, landing pages, CVs and game UI. It makes real designs with strong tools such as Open Design, with no human in the loop. When a job needs images, skills, examples, templates, GitHub repos, tools or software, the loop finds a donor, checks the license and brings it in. A design counts when a customer repo uses it.

Gives: thumbnail-readable covers for the factory's published listings (`samples/cover-b`, `designs/factory-gumroad-cover`); ad squares and landing heroes for marketing-studio (`samples/ads`); a Hebrew RTL CV and portfolio page for Maxim's job hunt through jobhunt (`samples/cv`, `samples/jobhunt`); a HUD, menu and button kit for forge and engine2040 (`kits/game-ui`); render, audit, thumbnail and judge tools any repo can run on its own covers (`arsenal.json`).

Takes: real briefs and orders from factory (`board/scoreboard.json`), jobhunt (CV drafts, job ads) and marketing-studio (campaign packs); part-score and skill templates from marketing-studio, jobhunt and skillworks; rule sheets, `finish.mjs` and `vision-check.mjs` from center; the engine UI formats of engine2040 and forge; donors from outside: images, skills, examples, templates, GitHub repos, tools and software (`sprint/steals.md`).
