# covers/
Sharded cover archive, split by slug initial.
- a-m/ - slugs starting a through m.
- b/ - b-shelf view inside the a-m range.
- n-z/ - slugs starting n through z.
Open first: a-m/ for the oldest covers, else n-z/.
Covers here are outputs; briefs live in samples/.
New covers go in the shard matching the slug initial.
Keep these three shard paths; tooling expects them.
