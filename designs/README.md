# designs/ — delivered order folders

Each `O-NNN/` folder is one order delivery (brief.json, page.html,
tokens.css, out.png, thumb-256.png, design-audit.json, DESIGN-REVIEW.md).
Each delivery carries a `DELIVERY.md` (<=10 lines): file list, customer
landing spot, and that repo's proof command.
Open `DELIVERY.md` in the order folder first, then `page.html` / `out.png`.
`factory-gumroad-cover/` and `job/` are shared working folders, not deliveries.
`BATCH-2026-10-06.md` logs a batch run; root `design-audit.json` is a sample.
Do not edit a customer repo outside its `from-design-studio/<id>/` folder.
