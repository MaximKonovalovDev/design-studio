How it works

  1. Grid

    Columns are the sheet width divided by the frame width, rounded down. Rows work the same way.

  2. Memory

    Width times height times 4 bytes for every pixel, per frame and for the whole sheet.

  3. Engine values

    Godot H and V frames, Unity slice size and RPG Maker cell math come from the same grid.

Common questions

Does this upload my sprite sheet?

No. The count runs in your browser and nothing leaves this page.

What do I get out?

Columns, rows, total frames, memory per frame and per sheet, and setup values for Godot 4, Unity and RPG Maker.

Who owns my art?

You do. This page keeps no copy and claims no rights.
