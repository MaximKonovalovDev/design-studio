Import a sprite sheet into Godot 4

Learn your sheet's grid, import with Nearest filtering, then wire AnimatedSprite2D and SpriteFrames. About 5 minutes.

5-minute recipe. Godot 4.x.

A blurry sprite in Godot is almost always a filter setting, and a wrong animation is almost always a wrong grid. Fix both in that order and the rest is wiring.

The recipe

  1. Learn your sheet's grid

    A 4-frame walk cycle is usually a 2 by 2 grid. Try columns and rows until each frame looks right.

  2. Import with Nearest filtering

    Select the PNG, open the Import tab, set Filter to Nearest and reimport.

  3. Build the SpriteFrames animation

    Add an AnimatedSprite2D, create a SpriteFrames resource, add the frames in row order and set the speed.

Test at 1x first

Scale by whole numbers only (2x, 3x) so pixels stay square.

A first script

Play the walk animation when the node is ready.

@onready var hero: AnimatedSprite2D = $AnimatedSprite2D
func _ready() -> void:
	hero.play("walk")
