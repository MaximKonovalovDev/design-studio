## The one experiment (E1)

### E1 — Fix-once-per-render ledger with enriched error payload + hang-never-retries

- Source: `Nutlope/llamacoder` HEAD `components/code-runner-react.tsx`
  (`ErrorMessage` Copy + Try-to-fix `disabled={isFixPending}`;
  `formatErrorForFixPayload` console-error `- ...` append;
  `autoFixSentForFilesRef` once-per-`filesKey` auto-fire;
  `PREVIEW_WATCHDOG_MS` 60s hang with `canAutoFix: false`;
  `findMissingPreviewModules` rewrite directive; `data-preview-phase` /
  timing metrics on the wrapper), file SHA cc357bb, plus
  `lib/chat-auto-fix.ts` (`FIX_REQUEST_PREFIX`, `shouldAllowAutoFix`,
  `describePathlessFenceProblem`), file SHA 924f2ad6. License: MIT (LICENSE
  SHA 9882e628 read live 2026-10-02, Copyright (c) 2024 Hassan El Mghari).
- What it does: the repair loop stops re-firing on the same broken render and
  stops retrying hangs, while every real fix request carries the enriched
  payload (fatal + console errors seen before it, or the rewrite directive for
  missing imports / the re-send-with-paths directive for pathless fences).
  Concretely: a fix ledger keyed on the render identity (donor: `filesKey`;
  ours: the iteration's diff-score + judge-error signature) fires at most one
  fix per broken render; a hang/stub render (`rendered:false`, donor: watchdog
  `canAutoFix:false`) records the error with zero fixes; the fix payload is the
  fatal plus prior warnings (donor: `formatErrorForFixPayload`), and a
  missing-asset failure carries a rewrite-without-it directive instead of a
  code patch (donor: `findMissingPreviewModules` message shape).
- Home: `tools/agent-shot.mjs` (exists, 221 lines read 2026-10-02); board row
  DS-04 (agent-01 loop, DONE — the loop exists, the ledger does not) feeding
  DS-28 (S06 strip + merge row, READY — this ledger is the retry half DS-28
  leaves open).
- Fixes: Scorecard row Judged quality (screenshot-diff repair converges: no
  double-fire on one failure, no doomed retries on hangs, richer payloads per
  attempt) with a Brief-to-render speed kicker (fewer wasted render cycles per
  convergence; donor's `bundleMs`/`totalMs` timing metrics suggest logging
  per-iteration ms in `iterations.json` while there).
- Net lines: ~20-30 new lines here (fix-ledger map + enriched-payload builder +
  hang guard in `runShotLoop`; fixture only in the `--check` path). wc both
  sides: donor `code-runner-react.tsx` ~700 lines + `chat-auto-fix.ts` ~100
  lines (live reads 2026-10-02); ours `agent-shot.mjs` 221 lines (read
  2026-10-02).
- Proof: `node tools/agent-shot.mjs --check` -> AGENT-SHOT PASS run 2026-10-02
  (11/11 checks, `loop runs >= 2 iterations: 2 iters`,
  `first iteration fails, best passes: 0:6 best:10`); extension proof is the
  same command with a 3-case fixture (double-fire same failing render asserts a
